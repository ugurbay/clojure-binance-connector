# Roadmap

## V1 — Tamamlandı

- Native Clojure Spot connector
- Public ve signed REST
- MARKET/LIMIT manuel emir akışı
- Unknown-execution reconciliation
- Market WebSocket ve signed User Data Stream
- Testnet release acceptance
- Secret, precision, retry ve production guard güvenlik kapıları

## Bakım Öncelikleri

- Binance Spot API changelog ve filtre değişikliklerinin düzenli takibi
- Güvenlik ve dependency güncellemeleri
- Daha güçlü gözlemlenebilirlik ve kullanıcı dokümantasyonu
- Açık bug'ların regresyon testleriyle kapatılması

## V1 Kapsamında Olmayanlar

Futures, Margin, Options, wallet transferleri, otomatik strateji, risk motoru, backtesting, UI ve kalıcı bot state'i connector V1 kapsamına eklenmeyecektir. Bunlar ayrı proje/major-version tasarımı gerektirir.

Roadmap taahhüt veya teslim tarihi değildir. Yeni özellikler resmî Binance sözleşmesi, güvenlik riski, bakım maliyeti ve community ihtiyacına göre değerlendirilir.
