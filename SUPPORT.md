# Destek

Bu proje gönüllü ve garanti verilmeyen açık kaynak desteğiyle sürdürülür.

## Nereye Başvurmalıyım?

- Kurulum/kullanım: önce [Başlangıç Rehberi](docs/GETTING_STARTED.md) ve [Sorun Giderme](docs/TROUBLESHOOTING.md).
- Yeniden üretilebilir bug: GitHub bug report şablonu.
- Özellik önerisi: feature request şablonu; V1 kapsam sınırını dikkate alın.
- Güvenlik açığı: yalnız [SECURITY.md](SECURITY.md) içindeki private kanal.
- Binance hesabı, API key yetkisi veya exchange sorunu: Binance'in resmi destek kanalı.

## Destek Talebine Eklenecekler

- İşletim sistemi, JDK ve Clojure CLI sürümü
- Connector commit/tag değeri
- Testnet mi production mı olduğu; credential değerleri olmadan
- Minimum yeniden üretim kodu
- Tam hata category/code/reason alanları; signed query ve secret olmadan
- Çalıştırılan doğrulama komutları

Maintainer belirli bir cevap süresi, çözüm veya geriye dönük uyumluluk garantisi vermez. Production trading olaylarında önce riski durdurun, ilgili API key'i kısıtlayın/iptal edin ve hesabı doğrudan Binance üzerinden kontrol edin.
