# Roadmap

> English counterpart of [ROADMAP.md](ROADMAP.md). | [Türkçe](ROADMAP.md)

## V1 — Complete

- Native Clojure Spot connector
- Public and signed REST
- Manual MARKET/LIMIT order flow
- Unknown-execution reconciliation
- Market WebSocket and signed User Data Stream
- Testnet release acceptance
- Security gates for secrets, precision, retries, and production access

## Maintenance Priorities

- Regularly track Binance Spot API changelog and filter changes
- Security and dependency updates
- Stronger observability and user documentation
- Close open bugs with regression tests

## Outside V1 Scope

Futures, Margin, Options, wallet transfers, automated strategies, a risk engine, backtesting, a UI, and persistent bot state will not be added to Connector V1. They require a separate project or major-version design.

This roadmap is not a commitment or delivery schedule. New features are evaluated against the official Binance contract, security risk, maintenance cost, and community demand.
