# Support

> English counterpart of [SUPPORT.md](SUPPORT.md). | [Türkçe](SUPPORT.md)

This project is maintained with volunteer, best-effort open-source support and without any service guarantee.

## Where Should I Ask?

- Installation and usage: read the [Getting Started Guide](docs/GETTING_STARTED.en.md) and [Troubleshooting Guide](docs/TROUBLESHOOTING.en.md) first.
- Reproducible bug: use the GitHub bug-report template.
- Feature proposal: use the feature-request template and respect the V1 scope boundary.
- Security vulnerability: use only the private channel described in [SECURITY.en.md](SECURITY.en.md).
- Binance account, API-key permission, or exchange issue: contact Binance through its official support channels.

## Include This Information in a Support Request

- Operating system and JDK/Clojure CLI versions
- Connector commit or tag
- Whether the environment is Testnet or production, without credential values
- A minimal reproduction
- Complete safe `category`, `code`, and `reason` fields, without signed queries or secrets
- The verification commands you ran

The maintainer does not guarantee a response time, resolution, or backward compatibility. For a production trading incident, stop the risk first, restrict or revoke the relevant API key, and verify the account directly through Binance.
